# Guia de Avaliação Formativa por Rubrica

Site estático para o Professor Tutor, com rubrica preenchível, orientações por atividade, jogos ilustrados e modelos de devolutiva ao professor e ao estudante. Os dados digitados permanecem apenas no navegador (localStorage); não há servidor nem envio de respostas.

## Publicar no GitHub Pages

1. Crie um repositório público ou use um repositório autorizado.
2. Envie `index.html`, `styles.css`, `script.js` e as imagens PNG para a raiz do ramo principal.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, ramo principal e pasta `/ (root)`.
4. Aguarde a implantação e confira a URL exibida pelo GitHub.

O conteúdo pedagógico foi adaptado do guia Word. As imagens dos jogos foram capturadas de `https://neilasalem.github.io/horizontes/index.html` em 29/09/2026. A capa foi fornecida pela autora do pedido. As produções exemplificativas do Word são simulações.
